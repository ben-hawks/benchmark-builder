# Overview

**Toy Linear Regression** is a minimal worked example bundled with the
`benchmark-builder` skill, demonstrating a complete, working Codabench competition
bundle: two features predicting one continuous target, code submissions, a two-phase
(development / final) structure, and an R²/RMSE leaderboard.

It exists to be pattern-matched and validated against, not entered — see
`references/codabench.md` in the skill for how each piece maps onto a real benchmark.
