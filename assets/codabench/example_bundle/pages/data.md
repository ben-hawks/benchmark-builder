# Data

Synthetic, generated by `scripts/generate_codabench_example_data.py` (fixed seed —
fully reproducible): `y = 2*x1 - 3*x2 + 5 + noise`, `noise ~ N(0, 0.5)`.

- **Training**: 60 samples, shared across both phases (`training_data.csv` /
  `training_label.csv`, two comma-separated columns / one column respectively).
- **Development test**: 20 samples (`dev_phase/`), used while iterating.
- **Final test**: 20 fresh samples (`final_phase/`), used once, for the real score.

`public_data/` mirrors the development phase's training and test data (**including**
labels, unlike the real held-out `input_data/`) so participants can explore and debug
locally before submitting.
