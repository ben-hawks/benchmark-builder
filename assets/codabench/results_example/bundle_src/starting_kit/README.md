# Starting kit

- `test_sample_ids.csv`, `holdout_sample_ids.csv`: the ids your predictions must cover.
- `sample_submission.zip`: the reference solution's predictions, in exactly the upload
  format (two CSVs at the zip root, columns `sample_id,y`).

Make your own: write `predictions_test.csv` and `predictions_holdout.csv`, then
`zip submission.zip predictions_test.csv predictions_holdout.csv` (no wrapping folder).
